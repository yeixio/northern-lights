Northern Lights packages

Package repositories for Northern Lights, for amd64 and arm64.

Debian and Ubuntu (apt)

sudo install -d /etc/apt/keyrings
sudo curl -fsSL -o /etc/apt/keyrings/northern-lights.gpg __BASE_URL__/northern-lights.gpg
echo "deb [signed-by=/etc/apt/keyrings/northern-lights.gpg] __BASE_URL__/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/northern-lights.list
sudo apt-get update
sudo apt-get install northern-lights
sudo systemctl enable --now northern-lights

Fedora, RHEL, Rocky, Alma (dnf / yum)

sudo curl -fsSL -o /etc/yum.repos.d/northern-lights.repo __BASE_URL__/northern-lights.repo
sudo dnf install northern-lights
sudo systemctl enable --now northern-lights

Then open http://localhost:3000 to create the admin account. Settings are in /etc/northern-lights/northern-lights.env.
